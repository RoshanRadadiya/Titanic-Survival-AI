# 🚢 Titanic Survival AI

A modern Streamlit web app powered by TensorFlow that predicts Titanic passenger survival probability using deep learning.

## Features

- Modern Glassmorphism UI
- Deep Learning Prediction
- Real-time Inference
- TensorFlow + Streamlit
- Responsive Dashboard

## Tech Stack

- Python
- Streamlit
- TensorFlow
- Scikit-learn
- Pandas

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
